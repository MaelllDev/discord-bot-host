## Assets

**Default logo** (`web/public/logo.png`) — an original asset of this project, generated by
[`scripts/generate-logo.mjs`](scripts/generate-logo.mjs) with no third-party artwork. Run
`node scripts/generate-logo.mjs` to regenerate it (change the colours/glyph constants in that file if
you want your own). It is covered by the project's MIT license.

**Heads-up for forks:** a personal BotPanel installation may use a downloaded logo (for example an
emoji from a CDN such as emoji.gg) as the favicon and sidebar icon. Those images usually have
*unclear redistribution rights*, so they are **not** part of this repository. If you replace
`web/public/logo.png` with artwork you did not create, check its license before publishing your fork.

Docker images referenced in the code (for example `node:22-slim`, `python:3.12-slim`) are pulled from
the registry you configure and carry their own licenses; BotPanel does not redistribute them.
